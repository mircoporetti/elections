## Elections AI Chat

### Run the app locally

Requirements:

- Node ˆ20

1. Create a `.env.local` file copied from `.env.example` and fill the `API_BASIC_AUTH` with your Base64 string composed by the credentials to call the backend API.

2. Install

    ```bash
    npm install
    ```
3. Run the app

    ```bash
    npm run dev
    ```
